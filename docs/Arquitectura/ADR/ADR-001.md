# ADR-001 — Arquitectura Base

**Fecha:** 2026-07-13

## Decisión tomada

Mantener la raíz del proyecto limpia y mover toda la documentación funcional a `docs/`.

La raíz del proyecto (`/`) solo puede contener:

- Archivos de configuración (`package.json`, `tsconfig.json`, `next.config.ts`, `.env*`, etc.)
- Carpeta `src/`
- Carpeta `public/`
- Carpeta `docs/`
- Carpeta `scripts/` (cuando exista)
- Archivos esenciales del proyecto (`README.md`, `CLAUDE.md`)

Todo lo demás debe vivir en una carpeta específica dentro de las anteriores. Nada de scripts sueltos, archivos `.txt` de notas, ni páginas o código fuente en la raíz.

**Estado:** ✅ Adoptada.

## Motivo

Para mayor rapidez en implementaciones con Claude.

## Alternativas consideradas

Se hizo revisión de todo el disco y se aplicaron cambios para agilizar la programación con este proyecto, y se determinó que no era el equipo ni el disco. Así que empezamos a optimizar el proyecto reduciendo archivos y agrupando documentos en carpetas, para dejar solo lo que tenga que ver con la estructura y el sistema en sí de GestForce.

## Impacto

Agilidad en el trabajo.

- ✅ Reduce complejidad.
- ✅ Mejora el rendimiento.
- ✅ Hace el código más fácil de mantener.
- ✅ Facilita el trabajo con IA.
- ✅ Prepara GestForce para crecer.
